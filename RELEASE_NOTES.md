# Release Notes

## v1.0.0

Initial public release of the Road Anomaly Detection project.

### Included in this release

- Streamlit application for road anomaly analysis from images, videos, and live camera input
- Two YOLO model weights ready for local inference
- Supporting inference and annotation-visualization scripts
- Setup and usage documentation for contributors and evaluators
- Archived evaluation outputs and sample predictions for reference

### Recommended use

1. Create a virtual environment.
2. Install dependencies from `requirements.txt`.
3. Launch the app with `python -m streamlit run main.py`.
4. Select a model and upload an image or video for inference.
